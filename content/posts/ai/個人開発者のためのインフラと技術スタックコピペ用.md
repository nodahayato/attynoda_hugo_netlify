# 個人開発向けスタック（役割ベース）

[フロントエンド]
- React + Vite
- Tailwind CSS
- Hosting: Cloudflare Pages

[API / サーバー]
- Runtime: Cloudflare Workers
- Framework: Hono
- Validation: Zod

[認証 / 認可]
- Better Auth

[データベース]
- Primary: Cloudflare D1
- Optional: Turso
- ORM: Drizzle ORM

[ストレージ]
- Cloudflare R2

[非同期処理]
- Cloudflare Queues

[メール]
- Send: Resend
- Receive: Cloudflare Email Routing

[言語]
- TypeScript（全レイヤー共通）
